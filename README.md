# Kerbal controller

A hardware controller for Kerbal Space Program 1 (Windows), built around a Teensy 4.1 and the
[KerbalSimpitRevamped](https://github.com/Simpit-team/KerbalSimpitRevamped) mod. Everything is 3D printed
on a 256 mm bed, so the console is split into five pieces.

**Status:** design stage. Parts are picked and the layout is drawn; nothing is ordered or built yet, and many
specs are seller claims still to be checked on the real parts.

## Layout

A raised, steep back strip of three pieces, with two lower wings at the front ends and the middle front left
open. Each piece is a printed shell with a removable 3 mm faceplate.

| Piece | Tilt | Holds |
|---|---|---|
| Left wing | 12 deg | translation stick, motorised throttle fader, time-warp encoder |
| Right wing | 12 deg | rotation stick, camera and display-page encoders |
| Strip left | 28 deg | 12 navigation / SAS keys, ABORT and STAGE ARM toggles |
| Strip middle | 28 deg | 2 OLEDs, 4 fuel bars, buzzer, Teensy, power input |
| Strip right | 28 deg | 12 action-group keys, 2 spare toggles |

Key choices: two JH-D400X-R4 joysticks, 24 MX-style keys with a pixel above each one, a 100 mm motorised
fader, 5 V power from a wall adapter, and one DB25 cable from each outer piece to the middle strip.

## Where things are

| File | What it has |
|---|---|
| `docs/decisions.md` | what is settled, why, and what is still open |
| `docs/parts-list.md` | every part, its status and where to buy it |
| `docs/wiring.md` | colour-coded wiring diagrams that render right on GitHub (SVGs in `docs/diagrams/`) |
| `docs/pinout.html` | the same diagrams as one page for a browser; both are generated by `docs/tools/gen_pinout.py` |
| `docs/wiring-checklist.md` | wire colours, per-piece wiring checklist and the checks before first power-up |
| `docs/pin-map.md` | Teensy pin assignment and the four DB25 pinouts, in tables |
| `cad/console_mockup_v1.scad` | the five-piece layout (current); renders in `docs/mockup/v1/renders/` |
| `cad/console_mockup.scad` | the earlier three-module layout (v0), see `docs/mockup/README.md` |
| `cad/test_plate.scad` | a small test plate for the key cutouts and pixel diffusers, see `cad/README.md` |

To rebuild images, install OpenSCAD and run `cad/build_mockup.sh` (v0) or the render commands at the top of
`cad/console_mockup_v1.scad`.

## Inspiration

The stepped layout (raised back panels, lower wings with the sticks) and the modular, swappable-faceplate
build style follow [Altitude Workshops' Simpit KSP](https://altitudeworkshops.weebly.com/simpit-ksp.html),
a five-panel Apollo-style KSP controller. That build uses one joystick and a throttle lever; this one uses
two joysticks and a motorised fader.
